Paste a GitHub token to save images straight into the site. Without one, dropped images are shrunk, renamed and downloaded for you to upload by hand.

How to make a token
  1. github.com → your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → atlas-of-warmth.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate, copy, paste here. It is kept only in this browser.

Connected. Images are saved to and appear on the map a minute or two later.

Drop several images here at once: each is matched by the type ID at the start of its file name (T014.jpg, T014 stove.png). Or drop one image onto a row below.
